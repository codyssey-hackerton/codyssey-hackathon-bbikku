# Lucide icons

Source: https://unpkg.com/lucide-static@1.66.0/ (ISC license, see LICENSE).

The pinned `font/lucide.ttf` and selected codepoints from `font/info.json` render through expo-font. This avoids requiring a new SVG native component in the current Expo runtime. The full font is bundled; changing versions requires refreshing both the font and glyph map together.
