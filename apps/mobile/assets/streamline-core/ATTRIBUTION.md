# Streamline Core 아이콘 출처

- 제작자: Streamline
- 원본: https://www.figma.com/design/666xyyhcegHd0qyIwAw5r4/10-000-Free-Icons---Open-Source-Icon-set--Community-
- 제작자 원본과 라이선스: https://github.com/webalys-hq/streamline-vectors/tree/main/core
- 라이선스: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/
- 이 폴더의 SVG는 Figma 원본에서 내보낸 파일이며 자체 경로를 수정하지 않았다. 미리보기에서는 색상과 크기를 CSS로 바꾸고 더보기 아이콘을 90도 회전했다.
- 사용·복제·변형 및 상업적 사용은 CC BY 4.0 조건에 따라 가능하며 적절한 출처와 라이선스 링크, 변경 사실을 표시해야 한다. 미리보기의 화면 밖 안내에도 출처를 표시한다. 실제 앱 배포 시에도 해당 출처 표시를 유지해야 한다.
- Core 이외의 무료·유료 세트는 다른 조건이 적용될 수 있다. 이 폴더에는 아래 Figma 문서의 Core 라인 페이지에서 확인한 항목만 담았다.
