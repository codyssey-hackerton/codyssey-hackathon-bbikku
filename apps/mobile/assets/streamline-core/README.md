# Streamline Core

The SVG files are the original project design exports; the transparent 96 × 96 PNGs are rasterized from those SVGs with macOS AppKit for display by React Native Image. The app changes icon size and tint, and rotates the more icon by 90 degrees. See [ATTRIBUTION.md](./ATTRIBUTION.md) for creator, source and CC BY 4.0 terms. Attribution must also remain visible in the distributed app.
