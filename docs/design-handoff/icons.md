# 삐꾸 아이콘 목록 — 검토 중

일반 UI는 사용자가 지정한 Figma 문서의 **Streamline Core Line** 원본을 사용한다. 중앙 AI 버튼과 삐꾸 캐릭터는 기존 시안을 유지한다. 이 문서는 규칙 검토용 초안이다.

원본: [사용자 제공 Figma 라이브러리](https://www.figma.com/design/666xyyhcegHd0qyIwAw5r4/10-000-Free-Icons---Open-Source-Icon-set--Community-) · [제작자 Core 라이선스](https://github.com/webalys-hq/streamline-vectors/tree/main/core) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

원본은 개인·상업적 사용과 변형이 가능하며 제작자와 출처, 라이선스, 변경 사항을 적절히 표시해야 한다. SVG 파일은 원본 그대로 보관하고 화면에서는 크기·색상을 바꾸며 더보기는 90도 회전한다. 실서비스에도 출처를 유지한다.

## 추가 확인

- Figma Core 라인에서 단순한 이전·다음·아래 화살표와 같은 모양을 확인하지 못해, 날짜 탐색 화살표는 기존 시안을 임시로 유지한다. 억지로 의미가 다른 화살표로 바꾸지 않는다.
- 동작별 색상과 크기는 일관되게 적용하고 모든 아이콘 단독 버튼의 접근성 라벨과 44×44 터치 영역을 확인한다.
- AI 비서의 중앙 캐릭터와 버튼 디자인은 이 일반 아이콘 세트로 대체하지 않는다.
