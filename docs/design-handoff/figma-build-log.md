# PIKKU Figma 제작 기록

- 파일: https://www.figma.com/design/YpAuzE5kCYzo6AQ3a59jmE
- 새 디자인 파일은 계정 Drafts에 생성했다. 다른 프로젝트와 파일은 수정하지 않았다.
- 사용자 지시: 연락 승인 화면의 미완성으로 잠긴 최종 검토 단계를 건너뛰고, 확인된 9개 화면을 새 Figma 파일로 옮긴다.
- 03 Screens: 기본 화면 9개와 일정 추가·더보기·지난 일정·완료·루틴 복구 등 예시 화면 16개. 연락 승인 화면은 별도 미제작이다.
- 02 Components: 하단 내비게이션 4종을 로컬 컴포넌트로 만들고 화면에서 인스턴스로 사용한다. 색상 변수와 텍스트 스타일도 생성했다.
- 시작 화면: 홈/default. 주요 탭, 일간 카드 스택, 일정 추가, 추천 확인 및 승인, 루틴 복구는 예시 프로토타입 링크를 사용한다. 상태 데이터가 동기화되는 실제 앱 동작은 아니다.
- 한글 폰트: Figma에서 Pretendard가 검색되지 않아 Noto Sans KR을 임시 적용했다. 프로필은 편집 가능한 임시 벡터 표현이며 원본 이미지와 동일하지 않다.
- 검수: Figma 구조 읽기에서 25개 화면과 총 3,485개 레이어, 1,029개 텍스트, 25개 내비게이션 인스턴스, 171개 연결 노드를 확인했다. 당시 각 텍스트의 직접 부모 기준 경계 이탈은 없었다. 주요 화면과 등록·복구 예시를 Figma 스크린샷으로 확인했다.
- `figma_audit.py`는 **통과하지 않았다**. 2026-11-01 수집 당시 1,346건이며 다수는 엄격한 4px 격자 검사다. 컴포넌트 재사용률, 버튼 상태 변형, 화면별 빈/오류 상태 등도 남아 있다. `figma-snapshot.json`, `figma-audit-report.json`, `figma-fix-list.md`는 해당 시점의 실제 검수 기록이다. 이 검수는 사용자가 보류하기로 한 연락 승인 화면을 여전히 검사 대상으로 포함하며, Streamline 아이콘을 사용하는데 Lucide 허용 목록을 전제로 하는 한계가 있다. 이후 제작 메모 위치와 내용을 수정해 노트 좌표는 현재와 다를 수 있다.
- 결론: 편집과 주요 이동을 검토할 수 있는 **디자인 시안**이다. 자동 검수 통과, 실제 기기 검증, 완성된 디자인 시스템으로 표현하지 않는다.

## 2026-11-01 카드·버튼 공통 부품 정리

- `02 Components`에 일정 카드 8개, 상태 버튼 5개, 일반 행동 버튼 3개 변형과 별도 사용 예시를 만들었다. 상태 버튼과 일반 행동 버튼은 시각 크기를 유지하면서 44px 터치 높이를 갖는다. 16개 인스턴스 예시와 상태 문구를 확인했다.
- 할 일·루틴의 완료 여부와 고정 약속의 참석 여부를 구분했다. 공통 카드의 제목·시간·유형과 상태는 텍스트 속성으로 수정할 수 있다.
- 기존 화면 전체의 카드를 새 인스턴스로 교체하면서 기존 노드를 제거하고 터치 대상과 화면 이동을 재생성하는 동작은 자동 검토에서 거절됐다. 기존 화면의 59개 카드는 손대지 않았으며 새 컴포넌트와 연결되지 않았다. 노드 제거와 동작 변경이 필요해 위험하다는 판단이다.
- 개발 전달 메모를 Figma 및 `design/developer-handoff.md`에 추가했다. 팀원에게 원본을 복제해 전달하기 전 접근 권한을 확인해야 한다. 복제는 아직 수행하지 않았다.
- 검증 시 기존 화면의 카드 59개가 남아 있고 홈·일간·루틴 대표 인터랙션이 유지됨을 확인했다. 공통 카드의 긴 제목과 가변 높이, 카드 더보기 터치 영역, 360·390·430px 반응형 화면은 추가 검증이 필요하다.
