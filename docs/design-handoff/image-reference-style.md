# 삐꾸 이미지 기반 디자인 기준 메모

상태: 작업용 초안. 화면을 다시 보며 확인할 기준이며, 최종 디자인 규칙이나 완성된 Figma 파일이 아니다.

## 1. 사용자가 직접 정해 준 방향

- iPhone과 Android를 대상으로 한다. 사용자 제공 홈·월간 캘린더·일간 캘린더·AI 비서 이미지의 색감, 레이아웃, 디자인 요소를 최대한 유지한다.
- 서체는 Pretendard를 쓴다.
- 하단은 홈 이미지의 순서인 홈 · 캘린더 · AI 비서 · 추가 · 루틴을 따른다. 가운데 AI 비서 버튼은 떠 있는 원형 강조 버튼이다.
- 루틴은 독립 탭으로 포함한다. 원본 루틴 이미지는 제공되지 않았으므로 다른 이미지의 카드, 배경, 색을 바탕으로 만든 제안이다.
- 사용자는 홈의 날씨 정렬과 프로필 잘림 수정을 요청했고, AI 버튼에는 친근하면서 정돈된 캐릭터 느낌을 원했다. 캐릭터의 최종 모양은 미확정이다.
- 사용자는 월간 달력에서 날짜를 선택해 일간 화면으로 이어지고, 날짜 칸은 정사각형에 가까운 간결한 그리드가 되기를 원했다.
- 사용자는 루틴 화면의 기존 색감과 카드, 여백, 내비게이션은 마음에 든다고 했으며, 등록·수정·날짜별 기록·복구 흐름을 구체화해 달라고 했다.

## 2. 현재 시안에서 사용하는 색의 예시

아래 수치는 제공 이미지에 맞춰 현재 HTML 시안에서 사용한 값이며, 이미지에서 측정하거나 사용자가 숫자까지 승인한 확정 토큰이 아니다.

| 용도 | 현재 시안 값 | 보이는 느낌 |
|---|---|---|
| 기본 배경 | `#E2E8FF` → `#F2F4FC` | 밝은 라벤더와 연한 파랑 그라데이션 |
| AI 비서 배경 | `#FDEAE2` → `#F1E6ED` → `#E0E2FE` | 연한 살구에서 라벤더로 이어지는 그라데이션 |
| 주요 카드 | `#FFFFFF` | 밝은 배경 위 흰색 카드 |

## 3. 배치와 구성

- 예시 프레임은 세로 390×844다. 이는 디자인 검토용 크기이며 실제 기기별 안전 영역과 동적 글자 크기는 따로 확인해야 한다.
- 큰 인사말과 작고 차분한 날짜를 상단에 두고, 일정 요약·추천·일정 목록을 둥근 카드로 나눈다.
- 카드에는 흰색 면과 부드러운 모서리를 사용하고, 색은 카드 전체보다 체크·세로 막대·작은 점으로 구분한다.
- 월간 달력은 날짜 숫자, 일정 점, 선택 표시 중심으로 두며 날짜 선택 즉시 일간 화면으로 이동하는 방식을 현재 시안에서 제안했다.
- 일간은 선택 날짜의 일정에 집중한다. 루틴은 7일 날짜 선택, 오늘/전체 보기, 날짜별 수행 상태를 구분한다.
- 추천과 확정된 일정을 구분하고, 시간 변경 제안은 사용자가 수락한 후에만 예시 캘린더에 넣는다.
- 홈과 오늘의 일간 일정 목록에서 현재 또는 다음 일정 카드를 전면에 두고 지난 일정 카드를 그 뒤에 겹친다. 별도 지난 일정 제목이나 요약은 표시하지 않는다. 노출된 레이어를 펼치면 기존 카드의 상태와 AI 메뉴를 사용할 수 있다.
- 일정·할 일·루틴 카드는 상태를 작은 글자로 표시하고 오른쪽에 텍스트 상태 버튼과 세로 점 더보기를 둔다. 할 일·루틴은 완료, 고정 약속은 참석 여부를 기록한다. 상태 버튼의 보이는 면은 작게 조정하고 누르는 영역은 44px 이상으로 유지하는 시안이다.
- 더보기의 맨 위에 연한 블루·라일락의 삐꾸에게 부탁하기를 둔다. 선택한 일정은 채팅 상단 카드로 이어지며, 예시 제안은 명시적으로 승인해야 반영된다.

## 4. 실제 제작 전 확인이 필요한 항목

- **시안과 확정의 구분:** 추천 흐름 1번의 프로필과 홈 배치는 수정 후 채팅에서 괜찮다고 확인되었으며 수정 전 의견도 보존했다. 5번은 ‘괜찮아요’가 저장되었다. 2~4번의 개별 반응과 캘린더·루틴과 홈 카드의 수정 의견은 저장되어 반영 중이며, 수정한 화면에 대한 최종 확인은 아직 받지 않았다.
- **글자와 터치:** 현재 미리보기에는 작은 보조 글자와 44px보다 작은 아이콘 버튼이 남아 있다. 이미지 느낌을 유지하면서 실제 iOS·Android에서 읽기와 터치 영역을 별도 검토해야 한다. 이미 검증했다고 보지 않는다.
- **AI 캐릭터와 아이콘:** 중앙 버튼의 친근한 캐릭터는 검토용이다. 최종 캐릭터와 일반 아이콘 체계는 미정이다.
- **날짜와 데이터:** 현재 예시는 2025년 4월 17일 오전 11:01에 시작해 시간이 흐르며 검토 화면에서 시각을 바꿀 수 있다. 예시 일정·루틴과 작성·대화 초안은 해당 브라우저에 저장된다. 예시 추천은 실제 AI나 개인 일정과 연결되어 있지 않다.
- **플랫폼:** 실제 iOS와 Android의 시스템 바, 뒤로 가기, 키보드, 화면 확대 및 360/390/430 폭은 아직 검증하지 않았다.
- **상태:** 빈 화면, 로딩, 오류, 오프라인, 권한 관련 화면은 일부만 시안에 있으므로 최종 확정 전에 별도 설계와 검토가 필요하다.
