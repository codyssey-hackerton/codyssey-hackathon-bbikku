# PIKKU 회의 맥락 정렬 — 초안

상태: PM 검토 전 · 작성일: 2026-10-31

## 자료와 신뢰도

- **S1 — 프로젝트 문서·공통 개발 계약 재구축 지침:** 사용자가 제공한 회의·멘토링 통합 요약. 회의 원문은 아님.
- **S2 — 프로젝트 심화 컨텍스트 및 제품 설계 의도:** 사용자가 제공한 보충 자료. 시나리오와 의도를 상세화함.
- **S3 — 현재 사용자 지시:** 5인 역할, 문서 생성 범위, 미확정 기술 처리. 명시적 최신 지시로 취급.
- **S4 — 독립 QA 및 보완 요청:** 14개 원본 스토리와 추가 논의 항목의 보존 요청. 당시 회의록에 접근하지 못했으며 이후 S5로 대조했다.
- **S5 — 통합 회의록 정리본:** 4건의 회의·멘토링을 종합한 1,293줄 내부 참고자료. US-01~US-14는 §4, 시나리오 A~F는 §5, 기능 후보 A~J는 §7. 실제 녹취 원문은 아니다. 내부 원본은 공개 문서에 링크하지 않으며, 아래 대조표에 확인한 맥락을 보존한다.
- 실제 회의 녹취·공식 가이드·기존 PRD·ADR v0.3 원문은 미확인. S5의 회의 시각은 정리본이 제공한 정보이며 녹취와 대조하지 않았다. S1·S2·S5를 공식 자료로 표시하지 않는다.
- **[확인]** 사용자 명시 지시, **[논의]** 회의 요약 속 방향·후보, **[멘토 제안]**, **[미정]**을 구분한다. 논의 항목은 MVP 승인이나 구현 완료를 뜻하지 않는다.

## 배경과 논의 흐름

일정을 기록한 후에도 준비·이동·작업 순서, 지연과 미완료에 대응해야 하는 판단 부담이 남는다. 삐꾸는 개인의 맥락을 반영해 계획·실행·복구를 돕는 서비스다. [확인: S1 §2, S2 §1]

S5 §3은 초기 회의 → 멘토링과 후속 논의를 설명한다. 초기 회의는 10월 30일 16:41경, 팀 회의 3은 19:39경, 후속 기록은 19:42경으로 기재한다. 뒤의 두 회의는 시작 시각이 겹쳐 선후관계를 확정할 수 없고, 멘토링 시각은 확인되지 않는다.

1. **초기 맥락 [논의]:** 일정 추천에서 출발. 이전 문서의 실제 문구는 미확인. [S1 §7]
2. **멘토링 [멘토 제안]:** 일정 정보만으로는 개인화가 충분히 드러나기 어렵다는 지적, 개인별 파인튜닝 검토 제안. 파인튜닝 채택은 미정. [S1 §3.4, S2 §2]
3. **후속 논의 [논의]:** 점진적 온보딩, 일정의 성격, 실행 지원, 영향을 받는 일정의 선택적 재추천, 미완료 복구와 사용자 승인. 각 항목의 회의별 귀속은 미확인. [S1 §3, S2 §3–8]
4. **현재 정리 [논의]:** Plan / Act / Recover는 기획 이해를 위한 가치 체계이며 확정 슬로건이 아니다. 모바일 앱을 지향하되 플랫폼·기술은 검토 중. [S1 §2, §6]

## 확정과 미결정

**[확인]** 사용자 지시로 현재 5인의 역할을 우선하며 기존 문서의 가상 개발 분업은 따르지 않는다. PRD·ADR v0.3은 초기 참고자료다. 현재 문서들은 검토 전 초안이다. [S3]

**[논의]** 추천을 사용자가 통제하고, 영향이 없으면 계획을 유지하며, 미완료 활동의 재시도를 지원하는 방향. 사용자의 승인 없이 일정 변경이나 제3자 연락을 하지 않는 원칙. 개별 기능의 최종 범위는 미정. [S1 §3–4, S2 §6–8]

**[미정]** 우선 사용자와 MVP·시연 범위, 기능별 우선순위, 온보딩 필수값, 정기 추천 시각, 무응답·거절 정책의 상세, 데이터 수집·보관 범위, 플랫폼과 기술 선택, 외부 연동·전화의 실현 가능성. 관측 기반 개인화의 실구현 여부도 미검증.

## 이전 맥락과 확인할 원문

S1은 초기 일정 추천에서 실행·복구까지 논의가 확장됐고, 웹 우선 제안에서 모바일 지향으로 검토 방향이 바뀌었다고 설명한다. 이는 **첨부 요약이 전하는 변화**이며, v0.3 및 회의 원문과 실제 비교한 결과가 아니다. 기존 문서에만 있는 내용의 현재 효력은 원문과 최신 합의 확인 전 판단하지 않는다.

확인 필요: 녹취와 회의별 결정자·최종 결론; 최근 회의에서 실제 확정한 범위; 멘토 발언과 팀의 채택 여부; 공식 제출 규정·서버 종료 시점; v0.3과의 구체적 차이 및 이후 번복 여부.
